🛠️ OPTIONAL (Recommended) – Limit SQL Server Memory

This makes SQL Server “well-behaved” on laptops.

Open SSMS → Connect → New Query:

$=EXEC sys.sp_configure 'show advanced options', 1;
  RECONFIGURE;

$=EXEC sys.sp_configure 'max server memory (MB)', 2048;
  RECONFIGURE;


🔒 This caps SQL Server at 2GB RAM max.
