
WhatsApp Flows uses a specific set of UI Components defined in the Flow JSON Schema. Unlike HTML, you are limited to these pre-defined types.
1. Core UI Component Types
Category	Component Types (type)
Containers	SingleColumnLayout, Section, Stack
Text	TextHeading, TextSubheading, TextBody, TextCaption
Form Inputs	TextInput, TextArea, CheckboxGroup, RadioButtons, Dropdown, DatePicker, OptIn
Selection	ImagePicker, Chips
Media	Image
Interactive	Button, Footer
2. Official Documentation Links
Component Reference: The master list of every UI element and its allowed properties.
Form Validation Guide: How to use the required and pattern properties for inputs.
Action Grammar: Documentation for navigate, complete, and data_exchange (the logic behind buttons).
Design Guidelines: Best practices for layout and user experience on mobile.
3. Notable Constraints
No Horizontal Rows: Everything is a vertical stack except for specific multi-column properties in CheckboxGroup or RadioButtons.
The Footer: Only one Footer is allowed per screen, and it is always pinned to the bottom.
Image URLs: Must be https and follow strict size/aspect ratio limits to avoid rendering errors on older phones.

Passing data to the next screen:
{
  "type": "Footer",
  "label": "Submit data",
  "on-click-action": {
    "name": "navigate",
    "next": { "type": "screen", "name": "NEXT_SCREEN" },
    "payload": {
      "name": "${form.first_name}",
      "lang": "${form.favourite_language}"
    }
  }
}
---------------------------------------------------------------------------------
Submitting data to the server:
{
  "type": "Footer",
  "label": "Submit data",
  "on-click-action": {
    "name": "data_exchange",
    "payload": {
      "name": "${form.first_name}",
      "lang": "${form.favourite_language}"
    }
  }
}
--------------------------------------------------------
In Flow JSON V4.0 you don't need to transfer the data via navigate since all data now is globally accessable, so instead you can keep payload as empty {}

"on-click-action": {
  "name": "navigate",
  "next": {
           "type": "screen",
           "name": "SCREEN_TWO"
          },
   "payload": {}
}
And on SCREEN_TWO you can reference it as:

{
  "type": "TextBody",
  "text": "${screen.SCREEN_ONE.data.field1}"
}

Building forms guidelines
In order to build Forms in Flow JSON you need to use Form components then provide the name and children properties

Children properties must be an array of Form components

Each Form component has its own property model, however the name property is required in all of them

Interactive components can not be used outside forms.
