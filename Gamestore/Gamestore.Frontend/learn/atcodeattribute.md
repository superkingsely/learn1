| Attribute                                  | Purpose                       |
| ------------------------------------------ | ----------------------------- |
| `[Parameter]`                              | receive data from parent      |
| `[CascadingParameter]`                     | receive global component data |
| `[Inject]`                                 | dependency injection          |
| `[SupplyParameterFromQuery]`               | read URL query                |
| `[EditorRequired]`                         | enforce parameter             |
| `[Parameter(CaptureUnmatchedValues=true)]` | capture extra attributes      |
| `[Authorize]`                              | protect component             |
| `[SupplyParameterFromForm]`                | bind form values              |
